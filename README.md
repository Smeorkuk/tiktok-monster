# Насколько ты TikTok-монстр?

Викторина на русском: 72 вопроса, 6 лет, режимы 18/36/72, 15 визуальных вопросов. Данные взяты из ранее собранного исследования; источники включены в каждую карточку.

## Игроки и администратор

Перед новой попыткой игрок указывает ник и подтверждает сохранение. Сервер хранит набор вопросов, выбранные ответы, даты начала и завершения, баллы и процент. Каждый ответ сохраняется; при сбое соединения можно повторить отправку на экране результата. Старые попытки первой версии остаются локальными и в статистику не импортируются.

`/admin` — панель владельца: количество попыток, завершённые прохождения, средний результат, поиск по нику, фильтр статуса, разбивка по вопросам, выгрузка отфильтрованной таблицы в CSV. Ник выбирает сам игрок, это не подтверждённая личность. CSV не содержит cookie или ключей доступа.

## Локальный запуск

Нужен Node.js 22.13+ (проверено на 24). Сторонних пакетов нет.

```bash
npm run build
npm test
npm run dev
```

Локальная база SQLite находится в `.local/preview.sqlite` и исключена из Git. Локальный сервер использует тестовую идентичность администратора только для разработки. Его нельзя использовать как публичный сервер.

## Файлы

- `web/` — интерфейс, вопросы, изображения и шрифты.
- `worker/index.mjs` — сервер, проверка доступа, пересчёт баллов и API.
- `drizzle/` — миграция базы D1 и журнал.
- `scripts/build.mjs` — собирает все ресурсы в единый Cloudflare Worker в `dist/server/index.js`.
- `scripts/dev.mjs` — локальный сервер с SQLite; `tests/` — проверки API.

## Размещение

Публичный тест: GitHub Pages. Папка публикации создаётся командой `npm run build:pages`. Ветка `gh-pages` содержит готовые статические файлы; в Settings → Pages выбрана публикация из корня этой ветки. После изменения интерфейса пересоберите и обновите эту ветку.

Кнопка «Админка» открывает серверную страницу с вводом пароля. Результаты хранятся в D1 на сервере ChatGPT Sites. Пароль не входит в код: сервер хранит PBKDF2-хеш, выдаёт подписанную HttpOnly-сессию на 12 часов и ограничивает попытки входа. Кнопка «Выйти» удаляет сессию браузера.

Секреты среды: `ADMIN_PASSWORD_HASH`, `ADMIN_PASSWORD_SALT`, `ADMIN_SESSION_KEY`. `FRONTEND_ORIGIN` разрешает запросы только с выбранного origin GitHub Pages. Пароль не добавляйте в репозиторий, Issues, Actions или файлы среды. Опциональный `ADMIN_EMAILS` сохраняет доступ владельца через доверенную идентичность инфраструктуры Sites.

Игровой браузер хранит случайный токен попыток. Он отправляется серверу отдельным заголовком; работа викторины на GitHub не зависит от сторонних cookie. Чужие токены не дают доступа к админке. GitHub Pages самостоятельно не исполняет API и не хранит результаты игроков.

Локальный сервер предназначен только для разработки. При переносе backend за пределы Sites необходимо обеспечить доверенную серверную аутентификацию, а не принимать заголовки личности из интернета.

Данные игроков, `.local/`, секреты и резервные копии базы не должны попадать в GitHub. Изображения мемов принадлежат соответствующим авторам; ссылки сохранены в `web/questions.json`.

## Проверки

`npm test` проверяет состав и выборку вопросов, подсчёт баллов, закрытые API, принадлежность попытки браузеру, сохранение пропусков, неизменность ответов, повторную отправку без дублей и фильтрацию поиска. Полноценная защита от читов не заявлена: вопросы с ответами доступны браузеру для локального разбора.
